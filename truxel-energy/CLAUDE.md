# Truxel Energy website — instructions for AI assistants

The design system in this folder is LOCKED. Read `DESIGN_SYSTEM.md` before any change.

- Do not change any value or name in `css/tokens.css`. Only append new tokens.
- Do not change existing rules in `css/components.css`. Only append new blocks or modifier classes.
- Use only existing tokens (`--c-*`, `--fs-*`, `--sp-*`, `--r-*`) in new HTML or CSS. No literal colours or sizes.
- Keep the three fonts (Archivo, IBM Plex Sans, IBM Plex Mono). Do not add fonts.
- Text and numbers in `index.html` may change; section order, classes and structure may not, unless the owner explicitly asks.
- When a new component is appended, add it to `styleguide.html`.
