# Truxel website — instructions for AI assistants

The design system in this folder is LOCKED (v2.0). Read `DESIGN_SYSTEM.md` before any change.

- Do not change any value or name in `css/tokens.css`. Only append new tokens.
- Do not change existing rules in `css/components.css`. Only append new blocks or modifier classes.
- Use only existing tokens in new HTML or CSS. No literal colours or sizes.
- Keep the three fonts (IBM Plex Sans, Instrument Serif italic for accents, IBM Plex Mono). Do not add fonts.
- Use only Truxel's own content. Never invent figures, clients, testimonials or steps.
- Text and images in `index.html` may change; section order, classes and structure may not, unless the owner asks.
- When a new component is appended, add it to `styleguide.html`.
