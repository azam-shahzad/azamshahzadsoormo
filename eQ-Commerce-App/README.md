# eQ Commerce App (HTML prototype)

Open `index.html` (Overview) in a browser. Every page links to the others through the top bar.

| Page | File |
|---|---|
| Overview | `index.html` |
| Approvals | `approvals.html` |
| My Work | `mywork.html` |
| Journey | `journey.html` |
| Leads | `leads.html` |
| Sales | `sales.html` |
| Listings | `listings.html` |
| Finance | `finance.html` |
| Logistics | `logistics.html` |
| Prep | `prep.html` |
| Pipeline | `pipeline.html` |
| Stock | `stock.html` |
| Projects | `projects.html` |
| AI Assistant | `assistant.html` |

Every page has a Grid view and an Orbit view (orbit icon in the top right).
The same files are packed in `../eQ-Commerce-App-HTML.zip`.

## Recent changes
- New toast system on every page (success, info, warning, error).
- Pipeline, Stock and Projects orbits group buses into bands, grades and phases.
- Figma: "eQ Commerce Theme (v4) Final" is bound to the tokens and components on "Components - v4 Final"
  (colours, text styles, glass effects, top bar, toasts, icons, buttons, pills, badges, toggles, dropdowns and inputs).
